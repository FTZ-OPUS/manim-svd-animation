# 奇异值分解 · 应用与证明升级版

成片：`奇异值分解科普动画_1080P60.mp4`。源码：`奇异值分解科普.py`。

按 FTZ-OPUS/manim-10-tasks 的中文楷体、深蓝背景、暖白正文、金色公式规范制作。公式书写统一约 1.48 秒，保留阅读停顿。本片为无配音动画。

## 内容

照片低秩重建引入 → 像素与矩阵 → 旋转 / 拉伸的几何分解 → SVD 定义 → 完整证明 → 图像压缩、PCA 与识别特征、伪逆与去噪。

证明依次说明：两个 Gram 矩阵的维数与对称性；半正定性；谱定理；奇异值为何是特征值的非负平方根；输出向量的正交性；左奇异向量与 AAᵀ 的关系；逐列拼装；零奇异值与长方形矩阵的补全。

## 一键渲染

双击 `重新渲染.command`，或者终端执行：

```sh
cd 奇异值分解
python -m pip install -r requirements.txt
python -m manim -qh 奇异值分解科普.py SVDExplainer --media_dir ./media
```

将 `-qh` 改为 `-ql` 可生成 480p15 预览。脚本不再覆盖命令行分辨率。

## 文件

- `素材/`：NASA 公共领域宇航员图像、实际 SVD 数据、各阶重建图与来源说明。
- `依赖/本机环境版本.txt`：作者电脑已安装依赖的精确版本。
- `requirements.txt`：主要 Python 依赖；渲染还需要本机已有的 LaTeX、dvisvgm 与 Kaiti SC 字体。
- `验收/`：数学核验、排版边界检查与逐章视觉预览。

## 数学与图像说明

图像重建均由 NumPy 实际计算 SVD，不用模糊滤镜代替。能量百分比表示前 k 个平方奇异值占比，并非识别或视觉准确率。存储量比较按相同精度的标量个数计算，不等同于 JPEG 文件体积。秩一图层用正负色彩展示并分别归一化。正交变换也可能包含反射，矩形 Σ 还可补零或压缩维数。PCA 示例已经中心化。
