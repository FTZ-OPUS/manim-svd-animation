# 奇异值分解：从图像重建到完整证明

一部约 5 分钟的中文 Manim 科普动画。开头用实际计算的照片低秩重建引入；接着通过几何变换讲解 SVD，并逐步证明特征值、奇异值和左右奇异向量之间的关系；结尾展示图像压缩、PCA 和伪逆的应用。
